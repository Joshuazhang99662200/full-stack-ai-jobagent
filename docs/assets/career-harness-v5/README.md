# README 暖色手绘配图

本轮沿用用户已确认的 [V4 主图](../career-harness-v4/workflow.png)，将四张辅助图统一为同一套暖白纸底、棕色手绘线条与简洁图标。薄荷绿用于证据、进展与通过状态，浅桃色标记差异或需核对项，橙黄色强调本人确认。主图文件未改动。

| 图片 | 内容与来源 |
|---|---|
| [简历交换](resume-exchange.png) | 三种准备触发条件、材料复核、实际成品审批与执行回读；依据[工作链路底稿](../../workflow-outline.md) |
| [运营与改进](feedback.png) | 联系阶段、转化观察、诊断、规则确认与效果复核；依据[实现范围](../../workflow-implementation.md)与[运营模块](../../pipeline-flywheel.md)，无虚构转化数据 |
| [证据与差异](evidence.png) | 将[合成输出](../career-harness-v2/samples.json)中的文本差异、来源与复核夹具结果重绘为说明图 |
| [审批摘要](approval.png) | 同一组合成输出中仅消息摘要变化的本地校验；表内展示摘要前八位 |

合成数据沿用 V2 的历史捕获记录，本轮按原数据重绘，未重新捕获程序输出。摘要清单同时保留捕获时与当前源码的摘要，便于区分版本。

图片由图像生成工具绘制，均为说明图。示例复核结论来自测试夹具，不代表真实模型独立复核；没有真实候选人资料、平台请求或发送授权。

所有宽度使用相同图片，并可点击查看原图。历史深色图和手机版仍保存在旧素材目录，当前 README 不再引用它们。

[画廊](gallery.html)便于并排核对全套风格；[提示原文](prompts.md)保留生成输入；[审核记录](review.md)区分 Hallmark 的页面容器检查与图片人工视觉、文字核对；[摘要清单](manifest.json)记录文件完整性。

Hallmark 使用本机安装的 V2.0.0，固定上游版本 `8f6969f8922caabde9de1784959eae11ddf68073`。本轮为沿用既有主图的品牌统一，不引入新的主题。

画廊复用旧素材目录中的 Host Grotesk，许可证见 [SIL OFL 1.1](../career-harness-v2/fonts/HostGrotesk-OFL.txt)。
