## 免费范围

个人为本人求职、学习和非商业研究可免费使用。学校、公益组织等按标准协议的 `Noncommercial Organizations` 条款处理，该条款还列明其他机构及资金来源规定。本页的例子帮助理解项目授权政策，不改写 LICENSE 原文。

需要商业授权时，价格、部署、服务、再分发、期限及支持范围在独立协议中确定。仓库没有通用“付钱即可自动获得全部权利”的许可，也没有新增联网激活、收费检测或远程停用代码。

## 从哪个版本开始

切换以**包含本次许可证修改的代码提交及其后续版本**为边界，不按用户下载日期或公告日期倒推。

- 切换前已按 Apache-2.0 提供的代码，其已授予权利仍保留。不能要求合法持有旧版本的人补交新协议的商业费用，也不能通过删除历史让原许可失效。
- 新增或有权改用新协议的内容按本次声明提供；与旧版相同或来源于第三方的内容仍可能存在既有许可权利，不能声称旧代码的免费商用能力已被技术性封锁。
- 保留旧标签、发布记录和原始产物。发布含本次修改的新包时使用新的发行版本，不覆盖此前已发布的同版本包，不把旧标签重指向新代码。
- [保留的 Apache 原文](../LICENSES/Apache-2.0.txt)用于历史及适用的第三方义务，不表示本次新增内容同时提供 Apache 选项。具体来源仍需结合历史记录及单独 notices 判断。

当前改动未创建新发布或修改已发布版本；CHANGELOG 的“未发布”部分记录本次切换。后续发布时，应在发布说明中给出实际生效提交和新版本号。

## 第三方内容不跟着换协议

React 等依赖、Hallmark 素材及其他第三方内容保持其自身许可证、署名和分发义务。根目录的商业收费规则不覆盖这些组件独立使用时已有的许可。[第三方 notices](../frontend/THIRD_PARTY_NOTICES.md)、[来源评审](oss-review.md)和各素材旁的许可证继续有效。

上游资料目前分别登记为依赖、adapter、子进程或仅参考；登记“仅参考”不构成可复制源码的许可。本次不重新授权未知来源，不删除上游 notices，也不因为选了非商业协议就允许复制所有其他非商业项目。

维护者只能对自己拥有或已取得足够授权的权利提供新协议和商业许可。Git 主分支的作者记录不构成完整著作权证明，不能代替贡献者授权、外部素材来源和雇佣关系等权属核对。未来外部贡献的要求见[贡献指南](../CONTRIBUTING.md#贡献的授权边界)。
