## 接入方式

`ConsoleDataSource` 定义在 `frontend/src/dataSource.ts`；`SourceConsole` 负责加载和刷新，`Console` 继续负责展示。只读快照、HTTP 查询和明确的合成模式共用渲染组件。新宿主传输模型以 `src/jobagent/schemas/console_host.py` 为权威，运行生成脚本更新 TypeScript；它们不取代 pipeline、审批或证据契约。

```tsx
import { SourceConsole, createHttpSource } from '@jobagent/polling-console';
import '@jobagent/polling-console/styles.css';

const source = createHttpSource();
<SourceConsole source={source} />;
```

宿主适配器须提供 `getSnapshot`、`getDefinitions`、`getJob`、`getMaterials`、`getHostState`、`getTodos`、`getChannelLogin`、`getBatch`。需要接入写入时，按能力提供可选方法，省略的方法会使对应动作禁用并说明原因，不构造不存在的 HTTP 端点。

| 接口 | 约束 |
|---|---|
| `recordDecision` | 候选人、岗位、联系轮次、材料版本、准确正文、附件摘要及去重键绑定；只记录决定 |
| `getOperation` | 核验同一去重键的真实业务结果；未知不自动重试 |
| `createExecutionBatch` | 先检查去重、屏蔽、业务状态、渠道、材料与审批；返回全文材料和排除原因 |
| `confirmExecution` | 只处理明确勾选项，核对当前材料与批准；逐项通过已有业务能力执行和回读 |
| `requestLoginRestore` | 只保存带时间的恢复请求；宿主独立服务去重、核对现有窗口，再处理登录 |
| `synchronize` | 先平台回读、再导入宿主事实、导出决定和有回读的执行事实，最后重读计数并列出差异岗位 |

真实适配器必须实施服务端幂等和版本校验、候选人隔离及单写手，不能依赖浏览器按钮状态。普通材料决定、文案意见和执行确认均不能旁路既有绑定摘要的人工审批。当前猎聘获批附件传输限制继续有效。

## 生产边界

默认 Python HTTP 服务保持只读。本次没有连接真实 Muse 数据库、真实招聘渠道、简历或队列；未接入的实际文件说明来源限制，不能以文件引用冒充附件内容。合成适配器的演示批准和回读仅供合成验收，绝不能用于真实投递。

`hostService.ts` 提供字段合并、同步顺序、个人待办筛选及安全文件链接等通用辅助函数。生产宿主仍需提供实际同步读写和回读实现；合成适配器不能被用作生产存储。它限制为合成候选人，采用追加历史、浏览器写入锁和存储版本冲突检查，遇到未知或损坏存储停止相关操作。

修改共享模型后运行 `python scripts/build_console_host_contracts.py`；`--check` 及 Python 测试校验生成文件一致性。前端验证使用 `npm.cmd run build`、`npm.cmd run test:ssr` 和 `npm.cmd test`，全部测试使用合成记录。

## 二级页面修正（2026-11-02）

基线为 PR16 合并后的 main `5f96f45`。只修正宿主模板要求的二级页面与列表联动，不改变冻结的接口名、Python 业务契约或投递能力。

- 关闭详情及嵌套清单恢复窗口、滚动容器和焦点；关闭本身不写决定、不发送请求。
- 拟发送正文保留白色编辑框；已保存的实际发送正文显示为灰底斜体只读。回读必须具有所选项、材料一致版本、正向依据和观察时间，不能凭成功标签切换发送态。
- 放弃按钮独立红色显示；详情按渠道提供“审批并发送 / 审批并投递”，只准备本岗位清单。材料变更后不复用旧的待执行清单，执行未知则继续核验，不能另起执行重试。
- 清单确认按钮上方回显全部已选岗位、渠道、准确全文、可读材料版本和实际附件；未选项目不执行。附件链接显示所属材料版本；没有实际文件与摘要绑定时不造预览链接。原始哈希仅进入排查信息。
- 旧版本待办继续显示并保留红点，回答按钮禁用并提示重审新版；未接入待办源显示待确认。计数按有个人待办的岗位去重，业务终态不因此重开。
- 历史按同一岗位、联系轮次及操作键合并显示，原始事件链完整保留。原始字段、路径和键只通过“更多 → 排查问题”读取。
- 进展直接显示宿主已保存正文，不由浏览器编造任务或为字数填充事实。宿主撰写时按模板控制在约 50–60 字；未保存说明时明确提示来源与状态限制。
- 渠道恢复只在明确掉线时出现；同一步骤的失败与状态未确认记录分别保留。真实宿主窗口恢复、实际附件内容和渠道执行均待宿主实测。

补充清单中的 pending 为待核验语义；传输仍使用既有 `unknown`，没有新增状态。逐页合成验收与验证结果见 [二级页面核验记录](react-secondary-pages-verification-2026-11-02.md)。
