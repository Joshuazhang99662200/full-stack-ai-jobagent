# CareerHarness 开源首页设计

日期：2026-10-29。用户已在阅读定位、首屏文案与配图建议后要求继续制作。

## 定位

主要读者是会使用 AI 助手的求职者，开发者复用作为第二层入口。展示名采用 CareerHarness，传达一套可以恢复、有证据约束、由本人决定对外发送的求职工作流。GitHub 地址、Python 包名、`jobagent` CLI 与 `job-hunting` Skill 保留现有名称，避免提前造成安装断链。

## 首页结构

首屏使用浅底、深绿和青柠色 SVG，给出名称、价值主张与真实工作流。正文依次展示一个合成案例、六项能力、无需个人资料的只读体验、不同宿主的入口、能力状态与开发者文档。长命令说明迁到 `docs/usage.md`。

三张图分别承担：品牌与流程；已确认证据和 JD 如何支持定向改写；审批与内容变更的关系。案例和流程图必须标注示意，不能伪装成真实产品界面或平台执行回执。SVG 无脚本、无远端字体、无外部图片，文字可搜索并提供标题与说明。

## 事实与边界

- 能力陈述以当前能力目录和实现为依据，外部宿主能力须验收。
- 搜索学习只调整软优先级；不表述成完整自动进化或自动投递。
- 独立复核、本人逐项审批、发送前摘要复核不能合并或弱化。
- 快速体验只运行合成数据读取与元数据发现，不触达招聘平台。
- 修正隐私文档中“删除本地即无远端副本”的过时承诺，说明外部模型、宿主和可选飞书通道。
- 基线唯一失败已复现为测试夹具时间过期；仅固定该测试的时钟，保留生产过期保护。

## 验收

核对 README 与迁移文档的本地链接、SVG XML、合成体验的 JSON 输出及图片渲染。执行仓库四项门禁；记录失败或环境限制，不以图片替代功能验证。不提交、推送或更改远端仓库设置。
