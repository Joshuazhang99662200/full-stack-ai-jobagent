# 固定母版简历入口

本技能保留固定模板任务的发现入口，执行规则统一进入 [job-hunting 简历路由](../job-hunting/optimizer/SKILL.md)，不再运行第二套简历链路。用户已在本次明确要求保留母版时沿用，不重复询问模式。

按需读取分发内自足的 [模板修改与逐页验收](../job-hunting/references/optimizer/template-tailoring.md)、[写作方法](../job-hunting/references/optimizer/writing-methods.md) 和 [Writer 宿主交接](../job-hunting/references/optimizer/writer-workflow.md)。固定模板方法已合入 job-hunting 的分发树；独立安装本入口时需同时具备 job-hunting，缺少则报告依赖缺失，不临时重建契约。

保留完整原件及未改内容，精简可追溯；只改本次允许的正文和加粗，不任意缩字、改边距或压成一页。缺证疑点留在内部稿，其余内容继续优化；最终依旧走既有事实核验、独立 review、完整性/逐页检查与本人逐份批准。角色说明和模板适配器不证明实际 Agent 已运行或成品已验收。
