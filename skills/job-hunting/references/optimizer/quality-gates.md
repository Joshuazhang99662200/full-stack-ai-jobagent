# 优化器质量门禁

```text
无证据支撑的主张 = 0
无证据支撑的指标 = 0
被证据反驳的主张 = 0
语义夸大 = 0
证据覆盖率 = 实质性主张的 100%
diff 覆盖率 = 被改动的实质性主张的 100%

```

校验器有权否决行文流畅的草稿。关键词或 ATS 目标绝不凌驾于事实接地之上。提示词的回归评测不放在本仓库:本项目是求职 agent,评测资产在仓库之外维护。

## 负面清单:自证式表述

简历句子写做了什么、产出了什么,不替候选人下评语。下列写法一律判为语义夸大,复核记为 `partially_supported` 并要求删改:

- 断言自身能力或价值:“沉淀了……能力”“具备……能力”“练就了……”;
- 自评熟练度:“熟练”“精通”“深度使用者”;
- 替经历下结论:“这段经验是……的直接来源”“为……打下基础”;
- 没有数字的效果断言:“有效提升”“显著改善”。有证据数字就写数字,没有就不写。

即使证据原文含这类措辞,改写时也要去掉,只保留可核对的动作与结果。用户明确要求保留的个别表述可作为显式例外,但必须写进复核理由,且仍要被证据蕴含。
