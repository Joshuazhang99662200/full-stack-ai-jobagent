# 完整简历的模板修改与逐页验收

用于本次已选“保留原结构”或“目标模板填充”的任务。按 [Writer 工作流](writer-workflow.md) 处理输入与事实；本文件只规定模板边界。已选“全盘重写”仍需采用本人选定布局，不能自动换主题。

## 基线与完整性

先读取完整原件/目标模板，保存源摘要、所有章节和槽位、可编辑范围与原始版面。保留独立原件，不从空白文档重新拼接后声称锁版。原有各项信息须有保留、改写或说明理由的删减去向；不能只交优化后的项目经历。目标模板空槽缺事实时报告，不用占位或猜测填满。

默认只改允许的正文措辞与约定加粗。保留标题/经历顺序、段落结构、字体字号、颜色、间距、缩进、编号、制表位、边距、页眉页脚、超链接、分节、分页和固定元素。局部精简后也核对留白与位置。不能静默删主要任职、关键章节或未改写部分。

文字超出区域先去重复和压缩表达；不能自行缩字、改边距或压成一页。不能在保真承诺下擅自换模板。缺可编辑源文件时说明局限；PDF 导入新主题不能标为保留原版式。

## 已有 Word 适配器的适用范围

仓库的 `jobagent.rendering.template_patch.patch_template(source, output, plan, allowed_paragraphs=...)` 消费现有 `TemplatePatch`，写到独立输出文件；它校验源摘要、原文与允许段落，修改纯文本与加粗并保留其他包成员。可用 `run_edits` 保留各 run 样式；整段替换不能覆盖混合非加粗格式。

此适配器有真实限制：不允许文本增长；不支持空原文槽、复杂字段/制表符/绘图/分页所在段落的整体替换。不要把它说成可填任意空模板的通用引擎。遇到不支持槽位时，宿主只有具备相应文档工具才能在本次授权范围内继续，并重新验证全成品；否则报告该制作环节未接入，保存已完成的完整正文与恢复点。不得修改适配器限制来掩盖失败。

它不证明事实、分页或最终审批通过。模板中的原文也须参与最终事实覆盖；不能把未审核内容作为“固定元素”跳过最终核验。

## 逐页验收

用相同 Word/LibreOffice 版本、字体环境和导出设置渲染原件与修改件，对比每一页的段落区域、页数、固定元素与换行。检查字体替换、遮挡、溢出、留白、非预期位移、断行和分页；改字或加粗后重新检查。页数或 XML 一致都不能替代视觉核验。

对实际导出的 PDF 执行 [既有 PDF 检查](../resume-pipeline.md)，核对完整正文与阅读顺序，检查批注、跟踪和内部说明未进入交付物。抽取顺序与既有门禁不兼容时如实报告失败，不忽略检查或暗换模板。

交接包括完整可编辑简历、实际核对的 PDF（请求时）、正文差异与删减原因、内部证据映射、独立复核及模板保真结果。只标记实际完成的阶段；缺渲染环境时可交内部预览并明确未完成视觉验收，不能宣称可投递。

需要新选布局时，可参考 [渲染与 ATS](../rendering-ats.md) 及原固定模板技能的排版资源目录；资源只帮助选型，不能触发上传或替换已选模板。分发包不依赖仓库外的资源目录才能完成既有模板流程。
