# boss-helper 研究笔记

BOSS 直聘的浏览器扩展（TypeScript, MIT），功能为优化 UI、去广告、**批量投递简历**、高级筛选、GPT 自动打招呼、**多账号管理**。

许可证兼容，但产品形态与本项目相反：本项目开宗明义「不是自动批量投递机器人」，且 [stop-conditions.md](../stop-conditions.md) 明确禁止用更换账号或代理绕开风控。因此它的批量投递循环、自动打招呼与多账号轮换**不移植**。

可参考的只有一层：BOSS 职位详情页的字段结构（标题、公司、地点、薪资、JD 正文、招聘方），用于将来实现**只读**的 `JobDiscoverySource`。该连接器遇到登录、验证码、验证、风控与页面结构变更时返回 `USER_INTERVENTION_REQUIRED` 停下交人。

它是浏览器扩展而非库，没有可供 Python 直接调用的进程边界；若要落地只读寻源，需要自建浏览器连接器，并把选择器与浏览器类型完全关在连接器内部，不得泄漏进核心模块。
